# Jewelry inventory prototype

Downloaded browser-accessible prototype from:
https://3515c8a98f11423a.d.superapp.now/prototype/index.html#inventory

## Run locally

Extract the ZIP, open a terminal in this folder, and run:

```sh
python3 -m http.server 8000
```

On macOS, `python3` may require installing Python first. Alternatively, serve this folder with your editor’s local web server.

Open http://localhost:8000/prototype/index.html#inventory

Use a local web server because JavaScript modules may not load if you double-click index.html.

## Included

Original index.html, styles.css, all 10 JavaScript files, and the views folder. The prototype files are unchanged. The privacy and support page responses are also included.

## Data and photographs

The published sample data includes four pieces, with no photographs. Edits and uploaded photographs saved in your browser’s local storage cannot be recovered from the public URL. This local copy uses its own browser storage.

The original Superapp links and externally hosted branding logo remain in the source. Core inventory styles and scripts are local.
